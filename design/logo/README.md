# yoshihiko.tech マーク（A5「斜めの切れ目」）

大文字の Y を 45° の切れ目で上下に分け、ベースラインにアンダースコアのカーソルを置いたレターマーク。
切れ目・縦棒の左下の角・カーソルの右上の角は、すべて同じ 45° でそろえている（サイトの HUD の角の切り方と同じ）。

## ファイル

| ファイル                         | 用途                                                                                   |
| -------------------------------- | -------------------------------------------------------------------------------------- |
| `final/yoshihiko-mark.svg`       | 3 色のマーク（背景は透明）。ダーク背景用                                               |
| `final/yoshihiko-mark-mono.svg`  | 単色のマーク。3 つの部品すべて `fill="currentColor"`。ライト背景・1 色印刷用           |
| `final/yoshihiko-favicon.svg`    | ブラウザのタブ用。#0D1C1F のタイル（右上と左下を 45° で切った正方形）の上に 3 色マーク |
| `export/yoshihiko-mark/*.png`    | 3 色マークの PNG（16 / 32 / 64 / 128 / 256 / 512 / 1024 px、背景透明）                 |
| `export/yoshihiko-favicon/*.png` | favicon の PNG（16 / 32 / 48 / 180 / 192 / 512 px）                                    |
| `brief.md`                       | 最初のデザイン依頼。色は当時のネオン配色のまま                                         |

- 置き場所: ロゴの元データ。サイトのビルドからは参照していない

- すべて `viewBox="0 0 100 100"`。width / height は付けていないので、CSS で大きさを決める
- 部品の id: `#y-upper`（上の Y）、`#y-lower`（下の脚）、`#cursor`（カーソル）、favicon のみ `#tile`
- 座標はすべて 0.5 単位のグリッド上。transform・外部参照・`<text>` はなし

## 色

| 部品                   | id         | 色                    |
| ---------------------- | ---------- | --------------------- |
| 上の Y（腕と上の縦棒） | `#y-upper` | `#DC6A35`（オレンジ） |
| 下の脚                 | `#y-lower` | `#5CC9BE`（ティール） |
| カーソル               | `#cursor`  | `#EEE7DA`（クリーム） |
| favicon のタイル       | `#tile`    | `#0D1C1F`             |

- 単色版の推奨色: ライト背景では `#17181D`、ダーク背景では `#ECE8F7`（`color` で指定）

## 背景による使い分け

- **ダーク背景（サイトの基本）**: 3 色マーク `yoshihiko-mark.svg` を使う
- **ライト背景**: 単色マーク `yoshihiko-mark-mono.svg` を使う。3 色版はクリームのカーソル（#EEE7DA）が背景に溶けて消えるので使わない
- **favicon**: `yoshihiko-favicon.svg` を使う。タイルを持っているので、ライトとダークのどちらのタブでも同じに見える

## 最小サイズ

実際に 16 / 24 / 32 px で描画して確認した結果。

| 版                   | 最小      | 備考                                                                                                           |
| -------------------- | --------- | -------------------------------------------------------------------------------------------------------------- |
| favicon / 3 色マーク | 16 px     | Y の形ははっきり読める。切れ目は約 1 px の暗い線になるが、オレンジとティールの色の差で上下が分かれて見える     |
| 単色マーク           | 24 px     | 16 px では切れ目が灰色のにじみになり、カーソルも縦棒に寄って見える。24 px 以上で切れ目とカーソルがはっきりする |
| ヘッダー             | 22〜30 px | どちらの版でも問題なし                                                                                         |

## クリアスペース

- 基準 X = 縦棒の幅 = SVG の一辺の 15%（例: 24 px で表示したとき約 3.6 px）
- マークの外形の四方に、X 以上の空きを取る
- SVG 自体が四方に 13.5〜14% の余白を持っているので、実用上は「SVG の枠の中に他の要素を重ねない」でほぼ足りる
- ヘッダーで横に `yoshihiko.tech` の文字を置くときは、SVG の枠から文字まで X の半分以上あける

## カーソルの点滅（CSS 案）

`#cursor` の不透明度を、1.1 秒周期で段階的に切り替える。動きを減らす設定の利用者には点滅させない。

```css
.site-logo #cursor {
  animation: yt-cursor-blink 1.1s steps(1, end) infinite;
}

@keyframes yt-cursor-blink {
  0% {
    opacity: 1;
  }
  50% {
    opacity: 0.12;
  }
}

@media (prefers-reduced-motion: reduce) {
  .site-logo #cursor {
    animation: none;
  }
}
```

- 外のページの CSS が `#cursor` に届くのは、SVG を HTML にインラインで埋め込んだときだけ。`<img src>` や CSS の `background-image` で読み込むと点滅しない
- 1 つのページに SVG を複数回インラインで埋め込むと id が重複する。その場合は、埋め込むときに id を変えるか、`class` に置き換えて指定する
- `steps(1, end)` で、前半は不透明度 1、後半は 0.12 のまま保つ（ターミナルのカーソルと同じく、なめらかに消えずにパッと切り替わる）
